# UAT — E0.01 Monorepo (npm workspaces + Turborepo)

## Objective

Verify the monorepo builds, lints, and tests from the repository root without feature code.

## Preconditions

- Node.js >= 20
- npm available
- Clean clone / working tree with dependencies installable

## Steps

1. From repo root, run `npm install`.
2. Run `npm run build`.
3. Run `npm run lint`.
4. Run `npm run test`.
5. Run `npm run typecheck`.
6. Confirm packages extend `tsconfig.base.json` (open any `packages/*/tsconfig.json`).

## Expected Results

- Install completes without workspace resolution errors.
- `build` succeeds for all apps and packages.
- `lint` exits 0.
- `test` exits 0 (scaffold smoke tests).
- `typecheck` exits 0.
- `@ac/web` can import `@ac/shared` and `@ac/ui`.

## Edge Cases

- Running `npm run build` twice uses Turbo cache (second run faster / cache hit).
- Deleting a package `dist/` and rebuilding regenerates outputs.
- `.env` remains gitignored; `.env.example` is present.
