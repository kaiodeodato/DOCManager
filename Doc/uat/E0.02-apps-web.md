# UAT — E0.02 apps/web Next.js 15 scaffold

## Objective

Confirm the web app builds and resolves monorepo packages via App Router.

## Preconditions

- E0.01 monorepo installed (`npm install` at root)
- Node.js >= 20

## Steps

1. `npm run build -- --filter=@ac/web`
2. `npm run test -- --filter=@ac/web`
3. `npm run dev -- --filter=@ac/web`
4. Open `http://localhost:3000`
5. Confirm page shows DOC Manager branding and `@ac/shared` / `@ac/ui` package names

## Expected Results

- Production build succeeds (App Router routes only)
- Smoke test passes
- Dev server serves home page without import errors

## Edge Cases

- Stopping/restarting `next dev` still resolves workspace packages
- No `pages/` directory exists under `apps/web`
