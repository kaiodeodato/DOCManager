# UAT — E0.03 Domain enums (`@ac/shared`)

## Objective

Confirm domain enums are exported from `@ac/shared` with unique values.

## Preconditions

- Monorepo dependencies installed (`npm install`)

## Steps

1. `npm run test -- --filter=@ac/shared`
2. Open `packages/shared/src/enums.ts` and confirm `DocumentStatus`, `DocumentType`, `JobType`, `UserRole`
3. From a Node REPL or a small script, `import { DocumentStatus } from "@ac/shared"` after build

## Expected Results

- Enum uniqueness tests pass (within and across enums)
- `DocumentStatus.NeedsReview === "needs_review"`
- Package build/typecheck succeed

## Edge Cases

- Adding a new enum value that duplicates another enum fails the collision test
- Apps import from `@ac/shared`, not local copies
