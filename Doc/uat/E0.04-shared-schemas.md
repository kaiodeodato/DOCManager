# UAT — E0.04 Zod schemas (`@ac/shared`)

## Objective

Verify main payloads validate via Zod and reject bad input.

## Preconditions

- E0.03 enums available
- `zod` installed in `@ac/shared`

## Steps

1. `npm run test -- --filter=@ac/shared`
2. Confirm suites for `DocumentUploadPayloadSchema`, `DocumentJobPayloadSchema`, `ExtractionResultSchema`
3. Optionally parse a sample upload payload in a scratch file using the schema

## Expected Results

- Each schema: valid parse succeeds; invalid value throws; missing required field throws
- `z.infer` types export (`DocumentUploadPayload`, etc.)
- Build/typecheck clean

## Edge Cases

- Confidence `1.5` rejected by `ExtractionResultSchema`
- Unknown `jobType` rejected
- Optional `checksumSha256` omitted still valid on upload
