# UAT — E0.05 UI tokens (`@ac/ui`)

## Objective

Confirm design tokens resolve in `@ac/ui` and are consumed by `@ac/web`.

## Preconditions

- Monorepo installed
- E0.02 web scaffold present

## Steps

1. `npm run test -- --filter=@ac/ui`
2. `npm run build -- --filter=@ac/web`
3. `npm run dev -- --filter=@ac/web`
4. Open `http://localhost:3000` and check the token color preview grid
5. Inspect computed styles: `--dm-color-accent` should be `#2563eb`

## Expected Results

- White background, blue accents, large radius, soft shadows
- `@import "@ac/ui/tokens.css"` works from `globals.css`
- `TOKEN_SWATCHES` exported from `@ac/ui`

## Edge Cases

- Removing the tokens import breaks theme utilities (`text-accent`, etc.)
- CSS export path remains `@ac/ui/tokens.css` (package `exports` map)
