# UAT — E0.06 `@ac/db` + migrations scaffold

## Objective

Verify db package still builds and migrations folder exists for E1.

## Preconditions

- Monorepo installed

## Steps

1. Confirm `supabase/migrations/.gitkeep` exists
2. Read `packages/db/README.md` (apply-migration instructions)
3. `npm run build -- --filter=@ac/db`
4. `npm run test -- --filter=@ac/db`

## Expected Results

- `PACKAGE_NAME === "@ac/db"`
- README documents `supabase db reset` / `db push` / `migration new`
- No SQL required yet (empty migrations folder is OK)

## Edge Cases

- Deleting `.gitkeep` without adding SQL may leave an empty untracked folder — keep `.gitkeep` until first migration
