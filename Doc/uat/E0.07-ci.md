# UAT — E0.07 CI pipeline

## Objective

Ensure GitHub Actions runs lint, typecheck, test, and build on PRs.

## Preconditions

- Repo pushed to GitHub with Actions enabled
- Lockfile committed (`package-lock.json`)

## Steps

1. Open `.github/workflows/ci.yml` and confirm triggers include `pull_request`
2. Open a PR (or push to `main`) and watch the **CI** workflow
3. Locally mirror CI: `npm ci && npm run lint && npm run typecheck && npm run test && npm run build`

## Expected Results

- Workflow job completes green
- Turbo cache step restores/saves `.turbo`
- Node 20 used

## Edge Cases

- Failing unit test must fail the workflow (non-zero exit)
- Concurrent pushes to the same ref cancel in-progress runs (`concurrency`)
