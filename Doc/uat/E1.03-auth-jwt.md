# UAT — E1.03 Auth + JWT claims

## Objective

Verify claims types, web auth stubs, and hook documentation.

## Preconditions

- `npm install` completed.

## Steps

1. Read `Doc/architecture/auth-jwt-claims.md`
2. Confirm `@ac/shared` exports `JwtOrgClaimsSchema`, `readOrgClaims`
3. Confirm `apps/web/src/lib/auth/` stubs exist
4. Run `npm run test -- --filter=@ac/shared` and web auth tests

## Expected results

- Claims parse from top-level and `app_metadata`
- `requireOrgClaims` throws when org claims missing
- Doc describes Custom Access Token Hook configuration

## Edge cases

- Incomplete claims (org without role) → `readOrgClaims` returns null
