# UAT — E1.05 tenant isolation

## Objective

Prove cross-tenant denial via unit tests; optionally via SQL when local DB is up.

## Preconditions

- Packages built.

## Steps

1. `npm run test -- --filter=@ac/db` — org-isolation suite green
2. Read `Doc/architecture/tenant-isolation.md`
3. (Optional) Seed two orgs and run `supabase/tests/tenant_isolation.sql`

## Expected results

- User A cannot access ORG_B rows in simulation
- Doc states full DB test requires Supabase local

## Edge cases

- User with zero memberships → no accessible org ids
