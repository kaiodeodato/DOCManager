# UAT — E1.06 Database types

## Objective

Confirm `@ac/db` exports `Database` and `npm run db:types` is documented.

## Preconditions

- Monorepo install.

## Steps

1. Open `packages/db/src/database.types.ts` — `Database` interface present
2. `npm run build -- --filter=@ac/db`
3. `npm run db:types` — keeps placeholder if CLI unavailable (exit 0)
4. Read `Doc/architecture/db-types.md`

## Expected results

- `import type { Database } from "@ac/db"` typechecks
- Script documents `supabase gen types typescript --local`

## Edge cases

- After local gen, placeholder is replaced; re-run build/typecheck
