# UAT — E3.04 / E3.05 Worker deploy + stuck-job alerts

## Objective

Confirm Render blueprint for worker-ocr and stuck/failed job alerting helpers.

## Preconditions

- Repo build works for `@ac/shared` and `@ac/worker-ocr`
- `render.yaml` present at repo root

## Steps

1. Open `render.yaml` and confirm service `doc-manager-worker-ocr` (`type: worker`).
2. Run `npm run test -- --filter=@ac/shared` and confirm `findStuckJobs` tests pass.
3. (Optional staging) Create Render Blueprint from `render.yaml` and enqueue a noop job.

## Expected results

- Worker service definition exists separately from web.
- Stale `processing` jobs and jobs with `attempts >= 3` produce `[stuck-job]` log lines via `formatStuckJobLog`.

## Edge cases

- Fresh pending jobs are not alerted.
- Full observability dashboards are E15 (out of scope).
